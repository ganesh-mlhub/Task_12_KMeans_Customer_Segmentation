# KMeans Customer Segmentation

## Objective
Segment mall customers based on their annual income and spending score using KMeans clustering.

## Dataset
- Mall Customers Dataset (Kaggle)

## Tools Used
- Python
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Steps Performed
1. Data loading and cleaning
2. Feature scaling using StandardScaler
3. Elbow method to find optimal clusters
4. KMeans clustering
5. Cluster visualization
6. Exported segmented dataset

## Results
- Identified 5 customer segments
- Created visual cluster representation
- Generated segmented customer CSV

- `KMeans_Customer_Segmentation.ipynb`
- `Segmented_Customers.csv`
